# Network‑Monitoring

A Python system for monitoring distributed nodes using gossip & heartbeat protocols, complete with CLI and logging.

## ✅ Features

- Heartbeat and gossip messaging between nodes  
- CLI-driven configuration  
- Structured logging per node and region

## 🔧 Tech Stack

- Python 3  
- `socket`, `threading`, custom logging

## ▶️ Usage

```bash
git clone https://github.com/Parkman97/Network-Monitoring.git
cd Network-Monitoring
python app_main.py  # Run a node
